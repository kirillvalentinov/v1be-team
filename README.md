# Генератор кроссвордов на тему живой природы

Этот проект создает кроссворд с вопросами на тему живой природы, включая вопросы о животных, растениях, грибах и микроорганизмах.

## Требования

- Python 3.6 или выше
- Установленные зависимости из файла requirements.txt

## Установка

1. Клонируйте репозиторий
2. Установите зависимости:
```bash
pip install -r requirements.txt
```

## Использование

1. Запустите скрипт:
```bash
python nature_crossword.py
```

2. Скрипт создаст файл `crossword.txt`, который будет содержать:
   - Сетку кроссворда
   - Вопросы по горизонтали
   - Вопросы по вертикали

## Особенности

- Более 50 вопросов о живой природе
- Случайное размещение слов в сетке
- Автоматическая генерация кроссворда
- Поддержка русского языка
- Сетка размером 23x23

## Категории вопросов

- Млекопитающие
- Птицы
- Рептилии
- Рыбы
- Насекомые
- Морские животные
- Растения
- Грибы
- Простейшие организмы
